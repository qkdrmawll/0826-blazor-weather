# 0826 Blazor 날씨 대시보드

Open-Meteo API(무료·키 불필요)를 사용하는 .NET 8 Blazor Web App(Interactive Server) 날씨 대시보드입니다.

## 개발 계획 (이슈 기반)
1. Issue #1 — 프로젝트 스캐폴딩 + Open-Meteo 서비스 계층 + 빌드/테스트 파이프라인 (선행)
2. Issue #2 — 도시 검색 + 현재 날씨 카드 (병렬)
3. Issue #3 — 시간별/일별 예보 (병렬)

> Issue #1 완료 후 #2, #3을 병렬로 진행합니다. 세 이슈가 모두 해결되면 개발이 완료됩니다.
